# 📝 GitHub Actions Beginner Quiz

## Question 1

Workflow files are stored in:

- A. `.github/actions`
- B. `.github/workflows`
- C. `.github/jobs`
- D. `.github/pipeline`

**Answer:** B

---

## Question 2

Which event allows manual workflow execution?

- A. push
- B. pull_request
- C. workflow_dispatch
- D. release

**Answer:** C

---

## Question 3

Which operating system is commonly used as a GitHub-hosted runner?

- A. Ubuntu
- B. Android
- C. Solaris
- D. ChromeOS

**Answer:** A

---

## Question 4

Which keyword specifies the runner?

- A. runner
- B. host
- C. runs-on
- D. execute

**Answer:** C

---

## Question 5

Which action checks out repository code?

- A. actions/build
- B. actions/deploy
- C. actions/checkout
- D. actions/git

**Answer:** C
